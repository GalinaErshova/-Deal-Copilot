# Demo case

Первый эталонный сценарий MVP: регулярный B2B-клининг офисного объекта.

Источник для подбора реального тендерного комплекта: публичные закупки, отобранные в ходе исследования проекта. Для первой разработки допускается загрузка любого простого комплекта с ТЗ + проектом договора + XLSX объёмов.

## Начальные demo-справочники

- стоимость часа клинера: 350 ₽/час;
- производительность: 800 м²/смену;
- химия и инвентарь: 7 ₽/м²/мес;
- техника: 2 ₽/м²/мес;
- целевая маржа: 15%;
- НДС: 22%.

Это демонстрационные значения. Они нужны для воспроизводимого MVP и будут заменены данными пилотной компании.
