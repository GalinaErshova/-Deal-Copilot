# Demo case

Первый эталонный сценарий MVP: регулярный B2B-клининг офисного объекта.

Источник для подбора реального тендерного комплекта: публичные закупки, отобранные в ходе исследования проекта. Для первой разработки допускается загрузка любого простого комплекта с ТЗ + проектом договора + XLSX объёмов.

## Начальные demo-справочники

- стоимость часа клинера: 350 ₽/час;
- производительность: 800 м²/смену;
- химия и инвентарь: 7 ₽/м²/мес;
- техника: 2 ₽/м²/мес;
- целевая маржа: 15%;
- НДС: 22%.

Это демонстрационные значения. Они нужны для воспроизводимого MVP и будут заменены данными пилотной компании.

## Демо-прайс-лист компании

`company-price-list.json` содержит три условных тарифа для проверки выбора позиции и расчёта: базовый, расширенный (+25%) и высокой интенсивности (+50%). Исходная ставка 180 ₽/м²/мес и норматив 800 м²/смену взяты из начальных демо-настроек приложения; варианты 225 и 270 ₽/м²/мес — синтетические сценарии, а не данные исполнителей. При старте приложения эти позиции загружаются только если прайс-лист компании пуст; существующие записи не изменяются. Перед подготовкой реального КП демо-позиции нужно заменить подтверждёнными тарифами и нормами компании.

## Справочник тарифов исполнителей

`provider-price-rates.json` содержит демонстрационные извлечения из четырёх прайс-листов: Lotus Cleaning, МСКСЕРВИС, Real Services и H2O Cleaner. Для каждой строки сохранены диапазон площади (если он указан), единица цены, ссылка, дата извлечения, способ получения данных и имя исходного CSV из корпуса `../data/A2_*`, расположенного рядом с репозиторием.

Массив `featured_ids` выделяет четыре примера для быстрого показа; полный каталог также доступен в интерфейсе.

Эти строки предназначены только для сравнения и тестирования: они не относятся к прайс-листу компании и не подставляются в расчёт КП. Период и условия тарифов в источнике указаны не всегда. Прайс-лист «Чистое дело» оставлен вне этого справочника: в демо-корпусе есть PDF, но нет проверенного табличного извлечения тарифов.
